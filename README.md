A comprehensive service and booking management web application for clients and professionals.

## Features
- Multi-role support (User & Professional)
- Authentication and onboarding workflows
- Booking, payment, and subscription management
- Profile management, reviews, search and inspiration modules
- Modular, scalable architecture

## Technology Stack
- React/Next.js (Frontend)
- TypeScript throughout
- RESTful API structure with modular endpoints
- State management: Custom stores
- Styling: CSS, custom components
- Utility libraries & hooks

## Getting Started

### Prerequisites
- Node.js (Recommended v16+)
- npm or yarn

### Installation
```bash
# Install dependencies
 npm install # or yarn install
```

### Running in Development
```bash
 npm run dev # or yarn dev
```

### Build for Production
```bash
 npm run build
 npm start
```
